📦 JECCI Inventarios

Descripción del proyecto

JECCI Inventarios es un sistema web desarrollado para facilitar la administración y el control de inventarios de una empresa.

Permite gestionar productos, registrar movimientos de mercancía, administrar bodegas y consultar información importante para la toma de decisiones.

Funcionalidades principales

- Gestión de productos.
- Registro de entradas y salidas de mercancía.
- Administración de bodegas.
- Transferencias entre bodegas.
- Gestión de proveedores.
- Administración de usuarios.
- Reportes de inventario.
- Alertas de existencias.
- Panel principal con indicadores de inventario.

Tecnologías utilizadas

- PHP: desarrollo del sistema.
- MySQL: almacenamiento de información.
- HTML y CSS: diseño de las interfaces.
- JavaScript: funcionalidades interactivas.
- XAMPP: servidor de desarrollo local.
- Visual Studio Code: editor de código.

Objetivo

Desarrollar una herramienta que permita mejorar la organización de productos, controlar los movimientos de inventario y facilitar la consulta de información.

Ejecución del proyecto

1. Instalar XAMPP.
2. Colocar la carpeta del proyecto en "C:\xampp\htdocs".
3. Iniciar Apache y MySQL.
4. Configurar la base de datos "sistema_inventario_jecci".
5. Configurar el archivo "config/conexion.php".
6. Abrir el proyecto desde "localhost" en el navegador.
